📖 KrysML Reference

Syntax, examples, and practice notes

KrysML (Krystyon's Modelling Language) is a simple, plain-text modelling language for describing systems.


KrysML is a structured way to take notes or jot down ideas, and this app (KrysML.com) lets you turn what you've written into diagrams oriented around what you need to communicate.


There are a few simple rules you need to follow to turn your notes into diagrams, and this guide explains them all.


Examples
Block — structure
What something is made of.
# Block Diagram
10. THESE: KrysML.com
    - Header
    - Left Panel
    - Centre Panel
    - Right Panel
    - Footer
Flow — process
What happens if, when or after something else happens.
000. START: launch KrysML.com @user ~browser
10. DO: select project name @user~header
     # Default is "New Project"
20. DO: triple click @user ~header
30. DO: type new name @user ~header
40. DO: create/edit diagrams @user ~right_panel
50. IF: finished
    - YES: save project @user ~header
    - NO: continue working @user
          LOOP TO 40
999. END: close tab/window @user ~browser
Cycle — feedback
What repeats. Reuse a step number to close the loop.
# Cycle
10. Create
20. Read
30. Update
40. Delete
    # - loops back to 10
10. Create
Interface — interaction
What systems or actors interact with each other.
# Interface Diagram
10. HAPPY: Server ~KrysML.com
    # - Delivers app over network to user's browser
20. HAPPY: Network
30. HAPPY: User's browser
40. HAPPY: User's data
    # - Data stays with user locally
30. HAPPY: User's browser
Try it yourself. Copy any example above, paste it into the Script editor, and watch the diagram render. Edit the words, change a number, add a step — see what happens.
Syntax
Element Format What it does
Number + dot 10. Every step starts with a number and a dot. Mandatory.
Keyword DO:, IF:, THESE:, START:, END:, HAPPY:, SAD:, MERGE:, PROCESS: Optional. Sets the node shape. A step with no keyword renders as a plain blue rectangle.
Colon DO: etc. Mandatory on all keywords except LOOP TO.
Branch dash - something Under an IF or THESE. Defaults to Yes.
Explicit branch - YES:
- NO:		 Both need the colon. Indented under the parent step.
Implicit decision ...something? A trailing ? works instead of IF:.
Loop LOOP TO n Returns to step n. No colon.
Case any case START:, Start:, start: all valid.
Branch numbers auto (40a, 40b) Generated by the parser. Don't write them.
Optional syntax
  • Tags — @actor for people, ~system for systems. Use them when the actor is intrinsic to the step; use a separate chapter when it isn't.
  • Comments — # at the start of a line disables it. // and <!-- --> also work. Pick one style and stick with it.
  • Deactivation — remove the dot after the step number to disable a step. Don't do this on branches.
  • Numbering — gaps of 10 or 100. Numbers are labels, not an order. Reusing a number creates a cycle.
  • Alternative forms — a trailing ? can replace IF:. PROCESS: and DO: are interchangeable.
Best practice
  • Start high. Detail belongs in code or engineering drawings.
  • Keep it simple. If a diagram is getting complicated, or a script is unreadable, that's telling you something.
  • Use multiples of 10 for step numbers. That leaves room to insert steps later without renumbering.
  • Experiment and adapt. The example diagrams are clean. Real-world scenarios usually aren't.

What is KrysML?

KrysML (Krystyon's Modelling Language) is a simple, plain-text modelling language for creating process, relationship, and interface diagrams, as well as basic flow charts.


KrysML.com is a single-file, offline-compatible, open-source tool that turns KrysML into diagrams. It's a free tool that will always be available to everybody.


KrysML.com exists to put automation into the hands of people who don't code, whilst protecting the privacy of their work.


KrysML.com values
  • Clarity and shared understanding over niche expertise
  • Solving real-world issues over memorising syntax and diagram shapes
  • Same input = same output over randomness of AI algorithms
  • Speed and simplicity over putting in more hours and effort

While there is value in the items on the right, I value the items on the left more.

To work offline:

Use Ctrl+S (or Cmd+S) to save the page. Open in a private/incognito window if you don't need to save what you are working on.
